# Binance UM Futures Martingale Grid Bot

Асинхронный торговый бот для Binance UM Futures (перпетуальные фьючерсы).
Реализует гармоническую сетку мартингейл с автоматическим тейк-профитом,
восстановлением после перезапуска и Telegram-уведомлениями.

## Структура проекта

```
martingale_v1/
├── main.py           # Точка входа, запуск всех трейдеров
├── symbol_trader.py  # Логика одного символа (цикл open→grid→TP)
├── strategy.py       # Математика: цены сетки, размеры ордеров, TP
├── exchange.py       # Обёртка над Binance REST + WebSocket
├── notifier.py       # Telegram-уведомления
├── db.py             # SQLite (aiosqlite) — персистентность состояния
├── config.json       # Настройки
└── requirements.txt
```

## Установка

```bash
pip install -r requirements.txt --break-system-packages
```

## Запуск

```bash
python main.py
# или с явным путём к конфигу:
python main.py --config config.json
```

## Конфиг (config.json)

| Поле | Описание |
|------|----------|
| api_key / api_secret | Binance API ключи (права на фьючерсы) |
| use_testnet | true для тестовой сети |
| telegram_enabled | Включить уведомления в Telegram |
| telegram_bot_token | Токен бота от @BotFather |
| telegram_chat_id | ID чата / пользователя |
| symbol | Торговая пара (напр. VICUSDT) |
| start_deposit | Сумма первого рыночного ордера в USDT |
| take_profit | Размер тейк-профита в % от средней точки входа |
| direction | "long" или "short" |
| distance_pct | Дистанция между первым и последним ордером в % |
| multiplier | Коэффициент увеличения размера следующего ордера |
| orders_qty | Общее кол-во ордеров (1 рыночный + N-1 лимитных) |
| max_tries | Сколько раз повторить цикл |

## Алгоритм

### Гармоническая сетка

Расстояния между ордерами плавно увеличиваются по мере удаления от точки входа.

```
end_price  = start_price * (1 +/- distance_pct/100)
first_num  = 1 / start_price
last_num   = 1 / end_price
diff       = first_num - last_num
coeff      = diff / (orders_qty - 1)
price_k    = 1 / (first_num - coeff * (k-1))
```

- SHORT: ордера на продажу выше точки входа
- LONG: зеркальные процентные шаги ниже точки входа

### Размеры ордеров

```
size[0] = start_deposit
size[k] = size[k-1] * multiplier
```

### Усреднение и пересчёт тейка

При срабатывании каждого лимитного ордера:
1. Пересчитывается средневзвешенная цена входа
2. Тейк-профит перемещается на take_profit% от новой средней
3. Отправляется Telegram-уведомление

### Восстановление после перезапуска

При старте бот:
1. Проверяет БД на наличие открытых сделок
2. Если позиция закрылась — отменяет осиротевшие ордера
3. Если позиция открыта — восстанавливает состояние и ждёт TP

## Telegram-уведомления

| Событие | Содержимое |
|---------|-----------|
| Открытие сделки | Монета, направление, цена, депозит, TP |
| Лимитный ордер исполнен | Номер X/N, новая средняя, расстояние до TP %, ожидаемая прибыль |
| Тейк-профит | Прибыль, баланс |
| Ошибка | Описание |
| Перезапуск | Информация о восстановлении |
